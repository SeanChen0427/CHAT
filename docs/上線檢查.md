# 上線檢查（Sean 版）

> 先照 `docs/上線步驟.md` 完成部署，再照本檔順序做。每一步的結果記到 `PROJECT_STATUS.md`。Meta 規則常變，以後台實際畫面為準。

## 1. 部署前

- [ ] Instagram 帳號是**商業或創作者**、**公開**帳號
- [ ] IG App：設定 > 訊息與限時動態回覆 > 訊息控制 > 已連結的工具 > **允許存取訊息** 已開啟
- [ ] 準備一個副帳號當測試用（不能用主帳號自己留言觸發）

## 2. Meta App 設定

- [ ] 建立 App，加入 Instagram 產品（API setup with Instagram login）
- [ ] 主帳號與副帳號都加為 **Instagram 測試人員**，並在 IG 網頁版 設定 > 應用程式和網站 接受邀請
- [ ] 取得長效 access token，權限含 `instagram_business_basic`、`instagram_business_manage_comments`、`instagram_business_manage_messages`
- [ ] Webhook Callback 與 Verify token：後台「帳號設定 > Meta 串接資訊」複製
- [ ] Webhook 訂閱欄位：`comments`、`messages`、`messaging_postbacks`、`messaging_referral`
- [ ] 隱私政策網址：`https://seanchen0427.github.io/CHAT/privacy.html`（帳號設定頁也有）

## 2b. Facebook 粉專設定

- [ ] 同一個 Meta App 加入 Messenger（粉專）使用案例，連結你的粉專
- [ ] 取得粉專存取權杖（權限：`pages_messaging`、`pages_manage_metadata`、`pages_read_engagement`、`pages_show_list`），填入 Supabase Edge Function secrets 的 `FACEBOOK_PAGE_ACCESS_TOKEN`
- [ ] 填入 `META_APP_SECRET`（應用程式設定 > 基本資料 > 應用程式密鑰）
- [ ] Webhook：同一個 Callback URL，Page 物件訂閱 `feed`、`messages`、`messaging_postbacks`、`messaging_referrals`
- [ ] 後台按「↻ 同步」：首頁出現粉專名稱、Facebook 貼文出現在貼文區（有「FB」標示）、沒有「尚未訂閱事件通知」提示
- [ ] 用來測試的個人 Facebook 帳號要在 App 有角色（開發模式限制）

## 3. 用副帳號實測（開發模式即可）

| # | 測試 | 預期 | 結果 |
|---|------|------|------|
| 1 | 建一條無門檻留言規則，副帳號留言關鍵字 | 收到私訊＋連結按鈕；後台名單出現副帳號 | |
| 2 | 建一條「要先追蹤＋要先留 Email」規則，副帳號**未追蹤**時留言 | 收到私訊＋「領取」按鈕 | |
| 3 | 按「領取」 | 收到「先追蹤我…」＋「我追蹤了」按鈕 | |
| 4 | 追蹤主帳號，按「我追蹤了」 | 收到索取 Email 訊息；名單顯示「有追蹤」 | |
| 5 | 回覆「好」 | 收到「這看起來不像 Email」提示 | |
| 6 | 回覆一個 Email | 收到交付訊息＋連結按鈕；名單出現 Email | |
| 7 | 建一條私訊關鍵字規則，副帳號私訊關鍵字 | 自動回覆 | |
| 8 | 建一條 ref 規則（ref=test），副帳號打開 `ig.me/m/<主帳號>?ref=test` | 自動回覆 | |
| 9 | 名單頁匯出 CSV，用 Excel 開 | 中文不亂碼 | |
| 10 | 後台首頁「同步」 | 不報錯；隔天檢查 token 到期日有值 | |
| 11 | 粉專影片留言關鍵字（用有 App 角色的個人 FB 帳號） | 留言下出現公開回覆；Messenger 收到私訊＋連結按鈕 | |
| 12 | 用該 FB 帳號私訊粉專關鍵字 | Messenger 自動回覆 | |
| 13 | 名單頁 | Facebook 聯絡人顯示「FB」與顯示名稱 | |

任何一步失敗：到後台執行紀錄看 Meta 錯誤碼，或到 Supabase 後台 > Edge Functions > api > Logs 看即時紀錄，貼給 Claude 修正。

## 4. 切 Live 並驗證一般粉絲

- [ ] Meta App 切到 Live（發佈）
- [ ] 請一個**不是測試人員**的朋友留言關鍵字
- [ ] 有收到私訊 → 不需要 App Review，完成
- [ ] 沒收到、執行紀錄也沒有這筆 → 需要 Advanced Access，走 App Review（需要商家驗證、示範影片、權限用途說明）
- [ ] Facebook：Meta 文件寫明標準權限只能處理「在 App 有角色的人」，一般粉絲幾乎確定要申請 `pages_messaging` 的 Advanced Access（App Review＋商家驗證）

## 5. 日常維運

- 名單頁可以處理「刪除我的資料」要求（刪除會一併抹除執行紀錄中的身分）
- 首頁出現熔斷提示：確認 IG 帳號沒有異常後按「熔斷復歸」
- 被大量留言時：系統有每分鐘／每日送出上限與緊急停止（首頁），不要關掉這些保護
