## 2. Meta App 設定（照後台「設定精靈」做）

2.1.0 起不用手動產生權杖、填 Supabase secrets、設定 Webhooks，全部在後台「設定精靈」完成。Meta 後台的實際位置（2026-10-20 Sean 實際操作確認）：

| 要做的事 | Meta 後台位置 |
|----------|---------------|
| 新增使用案例 | 左側「使用案例」>「新增使用案例」：管理 Instagram 的訊息和內容、透過 Messenger from Meta 與顧客互動、管理粉絲專頁的所有內容 |
| Instagram App ID／Secret | 「使用案例」>「管理 Instagram 的訊息和內容」>「自訂」> API setup with Instagram business login 頁面上方 |
| Meta App ID／Secret | 左側「應用程式設定」>「基本資料」 |
| Instagram 重新導向網址 | 同上 Instagram 頁面 >「Set up Instagram business login」> Business login settings > OAuth redirect URIs |
| Instagram 測試人員 | 左側「應用程式角色」>「角色」，再到 Instagram 網頁版接受邀請 |
| Facebook 重新導向網址 | 左側「商家專用 Facebook 登入」>「設定」>「用戶端 OAuth 設定」>「有效的 OAuth 重新導向 URI」（貼上後按 Enter，再儲存） |
| 應用程式網域（連結 Facebook 前） | 「應用程式設定」>「基本資料」>「應用程式網域」：填 `<你的 Supabase 專案 ID>.supabase.co` 與 `<你的帳號>.github.io`（精靈會顯示，可複製） |
| 粉專權限 pages_read_user_content | 「使用案例」>「管理粉絲專頁的所有內容」>「自訂」> 權限清單按「新增」；沒加會出現 Invalid Scopes 並中斷 |
| Webhooks（事件通知） | **不用填**，連結後系統自動設定；精靈出現「事件通知要手動設定一次」時才需要 |
| 隱私政策網址 | 「應用程式設定」>「基本資料」（切換上線前） |

## 3. 用副帳號實測（開發模式即可）

| # | 測試 | 預期 | 結果 |
|---|------|------|------|
| 1 | 建一條無門檻留言規則，副帳號留言關鍵字 | 收到私訊＋連結按鈕；後台名單出現副帳號 | |
| 2 | 建一條「要先追蹤＋要先留 Email」規則，副帳號**未追蹤**時留言 | 收到私訊＋「領取」按鈕 | |
| 3 | 按「領取」 | 收到「先追蹤我…」＋「我追蹤了」按鈕 | |
| 4 | 追蹤主帳號，按「我追蹤了」 | 收到索取 Email 訊息；名單顯示「有追蹤」 | |
| 5 | 回覆「好」 | 收到「這看起來不像 Email」提示 | |
| 6 | 回覆一個 Email | 收到交付訊息＋連結按鈕；名單出現 Email | |
| 7 | 建一條私訊關鍵字規則，副帳號私訊關鍵字 | 自動回覆 | |
| 8 | 建一條 ref 規則（ref=test），副帳號打開 `ig.me/m/<主帳號>?ref=test` | 自動回覆 | |
| 9 | 名單頁匯出 CSV，用 Excel 開 | 中文不亂碼 | |
| 10 | 後台首頁「同步」 | 不報錯；隔天檢查 token 到期日有值 | |
| 11 | 粉專影片留言關鍵字（用有 App 角色的個人 FB 帳號） | 留言下出現公開回覆；Messenger 收到私訊＋連結按鈕 | |
| 12 | 用該 FB 帳號私訊粉專關鍵字 | Messenger 自動回覆 | |
| 13 | 名單頁 | Facebook 聯絡人顯示「FB」與顯示名稱 | |

任何一步失敗：到後台執行紀錄看 Meta 錯誤碼，或到 Supabase 後台 > Edge Functions > api > Logs 看即時紀錄，貼給 Claude 修正。

## 4. 切 Live 並驗證一般粉絲

- [ ] Meta App 切到 Live（發佈）
- [ ] 請一個**不是測試人員**的朋友留言關鍵字
- [ ] 有收到私訊 → 不需要 App Review，完成
- [ ] 沒收到、執行紀錄也沒有這筆 → 需要 Advanced Access，走 App Review（需要商家驗證、示範影片、權限用途說明）
- [ ] Facebook：Meta 文件寫明標準權限只能處理「在 App 有角色的人」，一般粉絲幾乎確定要申請 `pages_messaging` 的 Advanced Access（App Review＋商家驗證）

## 5. 日常維運

- 名單頁可以處理「刪除我的資料」要求（刪除會一併抹除執行紀錄中的身分）
- 首頁出現熔斷提示：確認 IG 帳號沒有異常後按「熔斷復歸」
- 被大量留言時：系統有每分鐘／每日送出上限與緊急停止（首頁），不要關掉這些保護
