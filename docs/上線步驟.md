## 接下來（Sean）

1. 打開 https://seanchen0427.github.io/CHAT/ 登入（管理者帳號已建立）
2. 右上角頭像 > **設定精靈**，照 1～7 步完成：確認 IG 帳號 → 建立 Meta App → 填 App 資料 → 允許登入網址與測試人員 → **連結 Instagram** →（選用）**連結 Facebook 粉專** → 建立第一條規則
3. 用副帳號測試（`docs/上線檢查.md` 第 3 節）；測好後照精靈最下方「上線」把 App 切成 Live

## 更新後端（Claude）

推送新 commit 後，用 Supabase 連接器重新部署 `supabase/loader/index.ts`（把裡面的 commit 換成新的）。網頁由 GitHub Actions 自動發佈。
