# 上線步驟（Supabase＋GitHub Pages，全部在網頁上完成）

> Sean 版 2.0.0 起不需要在自己電腦安裝任何東西。後端與資料庫在 Supabase，後台網頁在 GitHub Pages。
> 標「Claude」的步驟由 Claude 完成；標「你」的步驟需要你本人在網頁上操作（涉及登入或密鑰，Claude 不能代填）。

## 已完成（Claude）

- Supabase 專案 `ig-fb-auto-dm`（東京）、資料庫結構、資料表保護（RLS）
- 系統自用密鑰（登入簽章、排程密鑰、事件通知驗證碼）已在資料庫內自動產生，不需要你設定

## 1. 讓 Claude 能推送到 GitHub（你）

在 Claude 的設定中連結你的 GitHub 帳號，並允許存取 `SeanChen0427/CHAT`。完成後告訴 Claude「GitHub 連好了」。

接著 Claude 會：推送程式碼、部署後端、開啟每分鐘排程、發佈後台網頁。

## 2. 開啟 GitHub Pages（你，一次性）

1. 打開 https://github.com/SeanChen0427/CHAT/settings/pages
2. 「Build and deployment」的 Source 選 **GitHub Actions**
3. 等 1～2 分鐘，後台網址：**https://seanchen0427.github.io/CHAT/**

（GitHub 免費帳號的 Pages 需要 repo 是公開的。程式碼裡沒有任何密鑰或粉絲資料，公開是安全的。）

## 3. 建立管理者帳號（你）

打開後台網址，第一次會顯示「建立管理者帳號」，輸入 Email 與密碼（至少 12 個字元）。這個畫面只會出現一次。

## 4. 建立 Meta App 並填入權杖（你）

照 `docs/上線檢查.md` 第 1、2、2b 節建立 Meta App，取得下表的值，然後到 Supabase 後台填入：

**填寫位置：** Supabase 後台 > 專案 `ig-fb-auto-dm` > Edge Functions > Secrets（或請 Claude 開輸入畫面，值只在 Supabase 頁面輸入，不會經過對話）

| 名稱（照抄） | 在 Meta 哪裡拿 | 必填 |
|--------------|----------------|------|
| `INSTAGRAM_APP_SECRET` | Instagram > API setup with Instagram login > Instagram app secret | 是 |
| `INSTAGRAM_ACCOUNT_ACCESS_TOKEN` | 同一頁產生的 Instagram 存取權杖 | 是 |
| `META_APP_SECRET` | 應用程式設定 > 基本資料 > 應用程式密鑰 | 要用 Facebook 才填 |
| `FACEBOOK_PAGE_ACCESS_TOKEN` | 粉專存取權杖 | 要用 Facebook 才填 |

填完約 1 分鐘生效。到後台右上角頭像 > **帳號設定**，「Meta 串接資訊」會顯示哪些已設定。

## 5. 設定 Meta 事件通知（你）

1. 後台 **帳號設定 > Meta 串接資訊**，按「複製」取得：
   - 回呼網址（Callback URL）
   - 驗證權杖（Verify token）
   - 隱私權政策網址
2. 貼到 Meta 後台：
   - Instagram 的 Webhooks：訂閱 `comments`、`messages`、`messaging_postbacks`、`messaging_referral`
   - Facebook 粉專（Messenger）的 Webhooks：同一個回呼網址與驗證權杖，訂閱 `feed`、`messages`、`messaging_postbacks`、`messaging_referrals`
   - 應用程式設定 > 基本資料 > 隱私政策網址
3. 回到後台首頁按「同步」，IG 帳號、FB 粉專與貼文就會出現

## 6. 測試

照 `docs/上線檢查.md` 第 3 節，用副帳號留言、私訊測試。出問題時把後台執行紀錄的錯誤，或 Supabase 後台 > Edge Functions > api > Logs 的內容貼給 Claude。

## 費用與限制（免費方案）

- 每月 50 萬次後端呼叫、500 MB 資料庫，自用綽綽有餘（每分鐘排程一個月約 4.3 萬次）
- 免費專案 7 天沒有活動會被暫停；本系統每分鐘排程與每日健康檢查都會產生活動，正常不會被暫停。萬一被暫停，到 Supabase 後台按 Restore 即可，資料不會遺失
