# 學員安裝手冊：建立你自己的一套 IG／FB 自動私訊

> 給想省下 ManyChat 月費、願意花 30～40 分鐘自己動手的人。全部在網頁上操作，不用寫程式、不用安裝軟體。
> 做完之後，你會有一個只屬於你的後台網址，資料存在你自己的帳號裡，別人看不到。

## 你會用到的三個免費服務

| 服務 | 用途 | 費用 |
|------|------|------|
| GitHub | 放工具的程式、提供後台網頁 | 免費 |
| Supabase | 在背後自動回覆留言、存你的資料 | 免費方案即可（每月 50 萬次呼叫、500 MB） |
| Meta 開發者 | 讓工具能代表你的 IG／FB 傳私訊 | 免費 |

建議用**電腦**操作，手機畫面太小容易按錯。

---

## 第 1 步：註冊 GitHub（已有帳號就跳過）

1. 打開 https://github.com/signup ，用 Email 註冊
2. 收驗證信、完成驗證（**一定要驗證 Email**，不然後面的自動安裝不會跑）

## 第 2 步：建立 Supabase 專案

1. 打開 https://supabase.com/dashboard ，按「Continue with GitHub」用剛才的 GitHub 帳號登入
2. 第一次會請你建立 Organization（組織）：名稱隨意，方案選 **Free**
3. 按「New project」：
   - Name：隨意，例如 `ig-auto-dm`
   - Database Password：按「Generate a password」，**複製存到你的記事本**（之後很少用到，但遺失很麻煩）
   - Region：選 **Northeast Asia (Tokyo)**，離台灣最近
   - 按「Create new project」，等 1～2 分鐘建好
4. 記下 **Project ID**：專案頁面網址 `supabase.com/dashboard/project/` 後面那段 20 個字的英文數字，例如 `abcdefghijklmnopqrst`。也可以在左下角 Project Settings > General 找到「Project ID」

## 第 3 步：產生 Supabase 存取權杖

這個權杖讓 GitHub 能幫你把工具裝進 Supabase。

1. 打開 https://supabase.com/dashboard/account/tokens
2. 按「Generate new token」，名稱填 `github-install`，按產生
3. **馬上複製**那串以 `sbp_` 開頭的文字存到記事本（離開頁面就看不到了）

不要把這串文字傳給任何人，包括在聊天裡貼給 AI。

## 第 4 步：複製一份工具到你的 GitHub

1. 打開 https://github.com/SeanChen0427/CHAT ，右上角按 **Fork**，再按 **Create fork**
2. 進到你自己那一份（網址會是 `github.com/你的帳號/CHAT`），點上方 **Actions** 分頁，按綠色按鈕 **I understand my workflows, go ahead and enable them**
3. 點上方 **Settings** > 左側 **Secrets and variables** > **Actions** > 綠色按鈕 **New repository secret**，新增兩個：

| Name（照抄） | Secret（貼上） |
|--------------|----------------|
| `SUPABASE_ACCESS_TOKEN` | 第 3 步那串 `sbp_` 開頭的權杖 |
| `SUPABASE_PROJECT_REF` | 第 2 步的 Project ID |

每新增一個按一次「Add secret」。

## 第 5 步：一鍵安裝

1. 點上方 **Actions** 分頁，左側點 **安裝與更新**
2. 右側按 **Run workflow** > 再按綠色的 **Run workflow**
3. 等 2～4 分鐘，出現**綠色勾勾**就完成了。接著「發佈後台網頁」會自動開始跑，也等它變綠色

紅色叉叉的話，點進去看最後一段的中文錯誤訊息，通常是第 4 步的兩個值貼錯，修正後再按一次 Run workflow。

## 第 6 步：開啟你的後台網頁

1. 點上方 **Settings** > 左側 **Pages**
2. 「Build and deployment」的 Source 選 **Deploy from a branch**
3. Branch 選 **gh-pages**、資料夾選 **/ (root)**，按 **Save**
4. 等 1～2 分鐘，打開 **`https://你的帳號.github.io/CHAT/`**（帳號一律小寫）

## 第 7 步：建立管理者帳號、跟著設定精靈走

1. 第一次打開會請你建立管理者帳號（Email＋至少 12 個字元的密碼）。系統沒有忘記密碼功能，請記好
2. 登入後會自動進入「**設定精靈**」，照畫面完成：確認 IG 帳號 → 建立 Meta App → 填 App 資料 → 允許登入網址 → **連結 Instagram** →（選用）連結 Facebook 粉專 → 建立第一條自動回覆

精靈的每一步都有「找不到？」提示；卡住時截圖精靈畫面問協助你的人，比較好判斷。

### Meta 後台位置速查

Meta 後台的按鈕名稱常改，下表是 2026 年 10 月實際操作時的位置：

| 精靈要你找的東西 | Meta 後台位置 |
|------------------|---------------|
| 使用案例 | 左側「使用案例」>「新增使用案例」：「管理 Instagram 的訊息和內容」；要接粉專再加「透過 Messenger from Meta 與顧客互動」「管理粉絲專頁的所有內容」 |
| Instagram App ID／Secret | 「使用案例」>「管理 Instagram 的訊息和內容」>「自訂」，頁面最上方 |
| Meta App ID／Secret | 左側「應用程式設定」>「基本資料」 |
| Instagram 重新導向網址 | 同一個 Instagram 頁面往下：「Set up Instagram business login」> Business login settings > OAuth redirect URIs |
| Instagram 測試人員 | 左側「應用程式角色」>「角色」，加完到 Instagram 網頁版接受邀請 |
| Facebook 重新導向網址 | 左側「商家專用 Facebook 登入」>「設定」>「有效的 OAuth 重新導向 URI」，貼上後按 Enter 再儲存 |
| Webhooks 頁面 | **不用填**，連結成功後系統自動設定 |

## 之後怎麼更新到新版本

Sean 推出新版時：打開你的 `github.com/你的帳號/CHAT`，按 **Sync fork** > **Update branch**。安裝與網頁發佈會自動重跑，幾分鐘後就是新版，你的資料和設定都會保留。

## 常見問題

| 狀況 | 處理 |
|------|------|
| Actions 分頁沒有「安裝與更新」 | 第 4 步第 2 點的啟用按鈕還沒按 |
| 安裝失敗：存取權杖無效 | 第 3 步重新產生權杖，到 Settings > Secrets 更新 `SUPABASE_ACCESS_TOKEN` |
| 安裝失敗：找不到這個 Supabase 專案 | `SUPABASE_PROJECT_REF` 貼錯，或專案還在建立中 |
| 網址打開是 404 | 第 6 步還沒存、或「發佈後台網頁」還沒跑完；也確認網址帳號是小寫 |
| 後台顯示「連不到系統後端」 | Supabase 免費專案 7 天沒使用會暫停（本工具有每日自動喚醒，通常不會發生）。到 Supabase 後台按 **Restore** |
| 只有我自己的帳號留言才會觸發 | Meta App 還在開發模式，照設定精靈最下方「上線」那段操作 |

## 安全說明

- 你的資料（粉絲名單、Email、權杖）只存在你自己的 Supabase，Sean 和其他學員都看不到
- GitHub 上的程式碼是公開的，裡面沒有任何密碼；你的密碼都存在 Secrets 和 Supabase 裡
- 不要把 `sbp_` 權杖、App Secret 傳給任何人
